Сервис автоматизации Threads

Приложение для работы с публикациями и комментариями в Threads через официальный Threads API.

Что делает приложение

  • публикует записи в аккаунт владельца по расписанию;
  • отслеживает комментарии к этим записям;
  • помогает готовить содержательные ответы на технические вопросы читателей;
  • передаёт коммерческие обращения владельцу для личного ответа.

Как мы обращаемся с данными

Приложение работает только с публично опубликованной информацией. Мы не собираем контакты, платёжные данные и личные сообщения. Обработанные записи хранятся 30 дней исключительно для того, чтобы не отвечать дважды на одно обращение, и удаляются автоматически.
